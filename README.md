## 🎓 Capstone Projects

### 🤖 [RFPro.ai — AI-Powered RFP Automation](./RFPro.ai%20-%20AI-Powered%20RFP%20Automation)

**Technologies:** Python · RAG · LLMs · ChromaDB · Streamlit

A Retrieval-Augmented Generation application that automates the Request for Proposal response process. It extracts content from enterprise documents, indexes it into a vector database, retrieves the most relevant context for each requirement, and generates accurate, context-aware responses using Large Language Models.

🖼️ [Demo & outputs](./RFPro.ai%20-%20AI-Powered%20RFP%20Automation/Demo)

A deep learning application that classifies chest X-ray images as **Normal** or **Pneumonia** using transfer learning, packaged with a Flask web application for real-time predictions.
