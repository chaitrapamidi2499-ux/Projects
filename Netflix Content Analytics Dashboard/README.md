# 🎬 Netflix Content Analytics Dashboard

> An interactive Tableau dashboard that explores Netflix's content library by analyzing titles, genres, countries, release trends, ratings, and content distribution to uncover entertainment industry insights.

---

# 📌 Overview

The **Netflix Content Analytics Dashboard** is an interactive Tableau visualization that provides insights into Netflix's global content library. The dashboard enables users to explore movies and TV shows through various dimensions such as release year, country, genre, ratings, duration, and content type.

Designed with interactive filters and visual storytelling, the dashboard helps identify content distribution patterns and evolving trends within Netflix's catalog.
