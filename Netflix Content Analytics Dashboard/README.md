# 🎬 Netflix Content Analytics Dashboard

## 📌 Project Overview

This project presents an interactive Tableau dashboard that explores Netflix's content library. The dashboard analyzes movies and TV shows across multiple dimensions, including release year, content ratings, genres, countries, duration, and date added to Netflix.

The dashboard enables users to interactively explore Netflix's catalog and identify trends in content distribution and growth over time.

---

## 🎯 Problem Statement

Streaming platforms host thousands of titles across different genres, countries, and content ratings. Understanding this content helps identify viewing trends, production patterns, and the evolution of Netflix's library.

The objective of this project is to build an interactive Tableau dashboard that provides meaningful insights into Netflix's content catalog.

---

## 🎯 Objectives

- Analyze Netflix's movie and TV show collection.
- Explore content growth over time.
- Study genre distribution.
- Analyze content ratings.
- Identify countries contributing the most titles.
- Examine movie durations.
- Create an interactive dashboard for exploration.
