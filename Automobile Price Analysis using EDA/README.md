# 🚗 Automobile Price Analysis

> An Exploratory Data Analysis (EDA) project that uncovers the key factors influencing automobile prices through data cleaning, visualization, and statistical analysis.

---

# 📌 Overview

Automobile pricing is influenced by several factors, including engine specifications, fuel efficiency, vehicle size, and manufacturer. This project performs an end-to-end Exploratory Data Analysis (EDA) on an automobile dataset to understand these relationships and identify the key features that impact vehicle prices.

The analysis focuses on data quality assessment, preprocessing, visualization, and extracting meaningful insights that can support data-driven decision-making.

---

# 🎯 Objectives

- Explore the structure and quality of the automobile dataset.
- Identify and handle missing values.
- Analyze numerical and categorical features.
- Discover relationships between vehicle specifications and price.
- Generate business insights through data visualization.

---

# ✨ Features

- Data exploration and inspection
- Missing value analysis and treatment

The dataset contains specifications and pricing information for different automobile models.

- Model

- Engine Cylinders
- Number of Doors
- Highway MPG

- Vehicle Size
- Vehicle Style
- Transmission Type
- Driven Wheels
- Market Category
- MSRP (Price)

# 🔍 Key Insights

- Engine horsepower has a strong positive relationship with vehicle price.
- Vehicles with higher engine cylinders generally have higher market prices.
- Engine horsepower and engine cylinders exhibit strong correlation.
- Fuel-efficient vehicles tend to have smaller engines and lower prices.
- Data cleaning improved the dataset quality, making it suitable for further analysis and predictive modeling.
