# 👥 PeoplesFirst HR Analytics Dashboard

> An interactive Tableau dashboard that analyzes workforce demographics, employee attrition, job satisfaction, and organizational trends to support data-driven HR decision-making.

---

# 📌 Overview

The **PeoplesFirst HR Analytics Dashboard** is an interactive Tableau dashboard developed to help HR teams understand employee demographics, workforce distribution, and attrition trends. The dashboard consolidates multiple HR metrics into a single interface, enabling organizations to identify factors contributing to employee turnover and evaluate workforce characteristics across departments, education levels, job roles, and age groups.

Through interactive filters and visualizations, stakeholders can drill down into workforce data and make informed decisions to improve employee retention and organizational performance.
