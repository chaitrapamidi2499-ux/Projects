# 📞 Connect Hub - Customer Support Analytics Dashboard

## 📌 Project Overview

This project presents an interactive **Power BI dashboard** developed to analyze customer support operations and service performance. The dashboard consolidates customer support data into meaningful visualizations, enabling stakeholders to monitor key performance indicators (KPIs), identify operational trends, and support data-driven decision-making.

---

## 🎯 Business Problem

Customer support teams generate large volumes of operational data every day. Without centralized reporting, it becomes difficult to monitor service quality, response times, and overall team performance.

The objective of this dashboard is to transform raw customer support data into interactive visualizations that provide actionable insights for business users.

---

## 📂 Dataset

The dashboard is built using the **Connect Hub Solutions** dataset, which contains customer support and operational data used for reporting and analysis.

---

## 🛠️ Technologies Used

- Microsoft Power BI
- Power Query
- DAX
- Data Modeling
- Interactive Visualizations

---

## ⚙️ Dashboard Development Workflow

- Imported customer support dataset
- Cleaned and transformed data using Power Query
- Built relationships and data model
- Created calculated measures using DAX
- Designed an interactive dashboard
- Added filters and slicers for dynamic reporting
- Developed business-focused visualizations

---

## 📊 Dashboard Features

The report consists of **two interactive pages**:

### 🏠 Home

Provides an executive overview of customer support operations through interactive KPI cards, charts, and business visuals.

### 📋 Grid

Presents detailed records in a tabular format for deeper analysis and data exploration.
