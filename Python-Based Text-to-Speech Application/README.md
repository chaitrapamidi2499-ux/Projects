# 🔊 Text-to-Speech Converter

> A Python-based desktop application that converts written text into speech using a graphical user interface with customizable voice and speech-speed options.

---

# 📌 Overview

The **Text-to-Speech Converter** is a Python-based desktop application developed to convert user-entered text into spoken audio.

The application provides an interactive graphical interface where users can enter text, select a preferred voice, choose the speech speed, and control speech playback.

The project uses **Tkinter** for the graphical user interface, **pyttsx3** for text-to-speech conversion, **Pillow** for image handling, and **Python threading** to execute speech without blocking the application interface.

# 🖥️ Application Interface

The application is built using **Tkinter** and provides a simple graphical interface for text-to-speech conversion.

The interface includes:

- Application logo
- Text input area
- Voice selection dropdown
- Speech-speed selection dropdown
- Play button
- Stop button
- Custom application icons

The user can enter text, select a voice and speech speed, and then generate speech using the Play button.
