# 📊 Swastik.co Sales & Forecast Dashboard

> An interactive Power BI dashboard that analyzes sales performance, profitability, customer segments, payment methods, shipping modes, product categories, geographic performance, and short-term sales forecasts to support data-driven business decisions.

---

# 📌 Overview

The **Swastik.co Sales & Forecast Dashboard** is an interactive **Power BI business intelligence dashboard** designed to provide a consolidated view of sales performance and future sales trends.

The dashboard contains two main pages:

- 🏠 **Home** — provides an overview of sales, profit, quantity, delivery performance, regional performance, customer segments, payment modes, shipping modes, categories, sub-categories, and state-wise sales/profit.
- 🔮 **Forecast** — provides historical daily sales trends, a **15-day sales forecast**, forecast confidence bounds, and state-wise sales performance.

The dashboard also supports interactive **region-based filtering**, allowing users to analyze business performance across different regions.

# 📈 Forecast Analysis

The forecasting component provides a short-term view of expected sales behavior.

The forecast visualization contains three important elements:

| Component | Description |
|-----------|-------------|
| Forecast | Expected sales value |
| Upper Bound | Upper limit of the forecast range |
| Lower Bound | Lower limit of the forecast range |

This allows users to understand not only the expected sales value but also the uncertainty associated with the forecast.
