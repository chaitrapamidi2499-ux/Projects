# 📊 Microsoft Excel Dashboard Projects

> A collection of interactive Microsoft Excel dashboards developed to transform raw business data into actionable insights using Pivot Tables, Pivot Charts, Slicers, and dashboard reporting techniques.
> 
---

# 📌 Overview

This repository showcases two interactive dashboard projects built entirely in Microsoft Excel. The dashboards demonstrate how Excel can be used as a powerful business intelligence tool to analyze financial performance and recruitment data through interactive reports and visualizations.

The projects leverage Pivot Tables, Pivot Charts, Slicers, Conditional Formatting, and Excel Dashboard Design to convert raw datasets into meaningful business insights.

# 📊 Project 1: Financial Performance Analysis

## 📌 Overview

Developed an interactive financial dashboard to analyze sales performance, profitability, customer segments, products, and discount bands across multiple countries.

### ✨ Features

- Interactive Dashboard
- Pivot Tables & Pivot Charts
- Country-wise Sales Analysis
- Product Performance Analysis
- Customer Segment Analysis
- Discount Band Analysis
- Dynamic Slicers

### 📊 Dataset

The dataset includes:

- Segment
- Country
- Product
- Discount Band
- Units Sold
- Manufacturing Price
- Sale Price
- Gross Sales
- Discounts
- Sales
- COGS
- Profit
- Month
- Year

### 🔄 Workflow

```text
Raw Data
    │
    ▼
Data Cleaning
    │
    ▼
Pivot Tables
    │
    ▼
Pivot Charts
    │
    ▼
Interactive Dashboard
    │
    ▼
Business Insights
```

### 🔍 Key Insights

- Compared sales and profits across countries.
- Identified top-performing products.
- Evaluated customer segment profitability.
- Measured the impact of discount bands on revenue.
- Analyzed yearly financial trends.

# 📈 Project 2: Recruitment Analysis

## 📌 Overview

Designed an Excel dashboard to analyze recruitment trends, applicant demographics, salary expectations, education levels, and interview outcomes.

### ✨ Features

- Interactive Dashboard
- Pivot Tables & Pivot Charts
- Interview Status Analysis
- Salary Analysis
- Education-Level Analysis
- Experience Analysis
- Dynamic Slicers

### 📊 Dataset

The dataset contains:

- Applicant ID
- Application Date
- Gender
- Education Level
- Years of Experience
- Desired Salary
- Job Title
- Interview Status
- City
- State

### 🔄 Workflow

```text
Raw Data
    │
    ▼
Data Cleaning
    │
    ▼
Pivot Tables
    │
    ▼
Pivot Charts
    │
    ▼
Interactive Dashboard
    │
    ▼
Recruitment Insights
```

### 🔍 Key Insights

- Monitored interview outcomes by education level.
- Compared salary expectations across applicants.
- Analyzed applicant work experience.
- Identified recruitment trends over time.
- Supported HR decision-making through interactive reporting.
