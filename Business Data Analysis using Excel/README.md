# 📊 Business Data Analysis using Microsoft Excel

## 📌 Project Overview

This folder contains Excel-based business analytics projects demonstrating the use of **Pivot Tables, Pivot Charts, Dashboards, Data Analysis, and Reporting**. These projects showcase how Microsoft Excel can be used to transform raw business data into meaningful insights for decision-making.

---

# 📂 Projects Included

## 💰 1. Financial Performance Analysis Dashboard

### 🎯 Objective

Analyze financial performance across different countries, products, customer segments, and time periods to identify profitability trends and business opportunities.

### 📂 Dataset

The dataset contains information including:

- Segment
- Country
- Product
- Discount Band
- Units Sold
- Manufacturing Price
- Sale Price
- Gross Sales
- Discounts
- Sales
- COGS
- Profit
- Month
- Year

### 📊 Dashboard Features

- Year-wise profit analysis
- Product-wise sales performance
- Country-wise product sales
- Segment-wise units sold
- Interactive Pivot Tables
- Pivot Charts
- Business summary reports

### 💡 Key Analysis

- Profit analysis across different customer segments
- Product performance by country
- Sales trends over time
- Segment-wise sales comparison

---

## 👥 2. Recruitment Analytics Dashboard

### 🎯 Objective

Analyze recruitment data to understand hiring trends, applicant demographics, salary expectations, educational qualifications, and recruitment status.

### 📂 Dataset

The dataset includes:

- Applicant ID
- Application Date
- Gender
- Education Level
- Years of Experience
- Desired Salary
- Job Title
- Recruitment Status
- Country
- State

### 📊 Dashboard Features

- Interview status analysis
- Education-level analysis
- Salary analysis
- Experience analysis
- Monthly recruitment trends
- Interactive Pivot Tables
- Pivot Charts

### 💡 Key Analysis

- Recruitment status by month
- Salary comparison based on education level
- Gender-wise applicant distribution
- Experience-wise applicant analysis
